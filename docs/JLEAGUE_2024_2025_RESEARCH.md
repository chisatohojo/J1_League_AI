# J.League Data Site: 2024・2025年J1の共通取得・検証

調査・最終確認日: 2026-09-14（日本時間）。新規取得は2024・2025年J1リーグ戦のみ。
中断時の未コミット変更・原本・生成物を保持して再開し、残っていた文書と最終確認を完了した。

## 結論と大会方式

公式の [2024年大会方式変更](https://www.jleague.jp/news/article/26789/) と
[2025年大会方式](https://www.jleague.jp/news/article/29445/)で、
両年とも20クラブのホーム＆アウェイ2回戦総当たりであることを確認した。
2024年から大会の正式名称は「明治安田Ｊ１リーグ」となるが、Data Siteの結果表の略称は従来と同じ `Ｊ１`。

公式確認済みのクラブ数 `N=20` と対戦回数2から、節数 `(N-1)×2=38`、各節 `N/2=10`、
年間 `N×(N-1)=380`、各クラブhome/away各 `N-1=19` を導出して原本と照合した。
取得件数や観測クラブ数に合わせて期待値を変更せず、既存の大会構造検証をそのまま利用した。

本体変更は `SEASON_FORMATS` の2年度設定と、比較先2024→2023・2025→2024の追加だけ。
HTML解析・キャッシュ照合・集計・CSV Validationの関数、15列の契約は変更していない。
年度専用の解析関数・スクリプトや新しい依存パッケージは不要だった。
両年とも `stage=full_season` で全380試合を正規化・検証し、CSV・集計JSON・人間レビューを生成した。

## 原本・キャッシュ・来歴

連続取得には2秒間隔を設けた。解析・再生成・中断からの再開後はすべて保存済みキャッシュを使用した。
Data Siteの試合詳細・ステージ別ページ・付随ファイル・robots.txtは取得していない。
公式大会方式の参照に加え、観測した2024年の日程特殊ケース1試合を公式発表で個別確認した。

## HTML構造・表記差分

両年とも `table.table-base00.search-table` が1個、ヘッダー1行＋データ380行、各行11列。
列名・順序は従来と同じで、全試合をサーバー応答のHTMLから取得できる。
節は `第n節第m日`、日付は `YY/MM/DD(曜日・祝日)`、得点は整数同士のハイフン区切り。
IDとsource URLはスコアセルの `/SFMS02/?match_card_id=数字` から取得する。
放送欄は放送先の情報のみで、中断・延期理由等の注記は見つからなかった。

必須10列と、stage・competition・round_label・kickoff_time・source_urlの追加5列を維持する。
チーム・会場の全角文字や略称を独自変換せず、元の実施日・節・ID・行順を保持した。

| 差分 | 2023→2024年 | 2024→2025年 |
| --- | --- | --- |
| 共通クラブ | 17 | 17 |
| 加わったクラブ表記 | 東京Ｖ、町田、磐田 | 岡山、横浜FC、清水 |
| 外れたクラブ表記 | 横浜FC | 札幌、磐田、鳥栖 |
| 加わった会場表記 | エコパ、プレド、ヤマハ、Ｅピース、Ｇスタ、Ｕ等々力 | アイスタ、メルスタ、ＪＦＥス |
| 外れた会場表記 | 札幌厚別、等々力、Ｅスタ | エコパ、プレド、ヤマハ、札幌ド、浦和駒場、長良川、駅スタ |

2024年の札幌ホームには「札幌ド」「プレド」、2025年の鹿島ホームには「カシマ」「メルスタ」「国立」が現れる。
会場の集合差分として保存し、同一施設や名称変更を自動判定・統合していない。
クラブ別の詳細な会場差分は集計JSON・人間レビューに含む。

## 特殊ケースと情報の限界

2024年のIDは30430～30809の380件で連続する。
2025年は第1～7節の70件が31361～31430、第8～38節の310件が32221～32530となり、790番号の空きがある。
欠番を取得漏れと見なさず、全対戦カード・各節・クラブ別の件数を検証し、全380試合の網羅性を確認した。
IDの再採番・欠番補完・ID順への並べ替えは行わない。

日程の例は以下のとおり。両年とも日付順と節順は一致しない。

| 年度 | 原本の例 |
| --- | --- |
| 2024 | 第25節浦和対柏（30678）が10-23、第29節磐田対横浜FM（30712）が11-16、京都対鹿島（30714）が11-17 |
| 2024 | 第28節浦和対川崎Ｆ（30700）が11-22。第28節全体の開催範囲は08-24～11-22の90日間 |
| 2025 | 第5節川崎Ｆ対横浜FM（31409）が04-09、神戸対広島（31410）が07-02。同節全体は03-08～07-02の116日間 |
| 2025 | 第20節浦和対京都（32341）が04-16、第30節の32449/32450が08-20 |

2024年浦和対川崎Ｆは [公式の再開試合発表](https://www.jleague.jp/news/article/28819/)を個別確認した。
8月24日に雷雨でハーフタイムに中止し、11月22日に後半から再開した試合である。
Data Siteの一覧は11-22・19:00・最終1-1を記録しているため、既存方針に従いそのまま1試合として保存する。
8月24日に最終結果を移したり、後半を別試合として追加したりしない。

この例ではCSVのmatch_dateは当初開始日と異なる再開日を表す。
現在の15列だけでは当初開始・中止・再開の各時点を表現できないため、将来の開始前予測や休養日数では扱いを決める必要がある。
今回の取得・Validationには未解決の不整合はなく、CSV仕様や時系列モデルの実装は変更していない。
その他の日程差分やID採番の原因は原本から断定しない。

2024年03-01川崎Ｆ4-5磐田（30440）、2025年08-31湘南4-5Ｇ大阪（32428）などの大得点も正常な整数として検証した。
両年とも入場者0はない。入場者・放送情報は従来どおり原本に保持し、CSV列は増やしていない。
