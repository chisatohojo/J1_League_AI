# J.League Data Site: 2017年J1の取得・共通処理適用検証

調査・検証日: 2026-09-13。対象は2017年J1リーグ戦のみ。
中断前に取得したHTMLと未コミットの実装を再利用して検証を完了した。

## 結論と適用判断

2017年は18クラブによる1ステージ・ホーム＆アウェイの総当たりリーグ戦。
2015/2016年の2ステージ制から変更されたことを
[Ｊリーグ公式の2017年大会方式発表](https://www.jleague.jp/news/article/7829/)で確認した。
期待値は各クラブ34試合、年間 `18 × 34 ÷ 2 = 306` 試合となる。

[Data Siteの2017年J1一覧](https://data.j-league.or.jp/SFMS01/search?competition_frame_ids=1&competition_years=2017&tv_relay_station_name=)
を1回取得した結果、同じ検索結果表・11列に全306試合が含まれていた。
大会表記が `Ｊ１`、節番号が1～34であるため、2ステージを前提にした共通処理はそのままでは適用できなかった。
この差分を実装前に報告し、確認済みの年度形式を設定で明示する範囲に変更を限定した。

2017年は `stage=full_season` として正規化し、既存CSV Validationを変更せず全306件が通過した。
CSVの再読込も一致。2015/2016年の既存5出力はバイト単位で完全一致を維持した。
ネットワーク取得器は今回実装しておらず、共通CLIは保存済みHTMLだけを読む。

## 日程上の特殊ケース

原本の放送情報欄には日程に関する注記が3行あった。注記の本文はHTML原本に保持し、CSVには既存と同じ15列を出力する。

| 対象 | 実施日・内容 |
| --- | --- |
| 第13節 Ｇ大阪 対 鹿島、川崎Ｆ 対 浦和 | 2017-07-05。原本にはACLの影響で同日に開催した旨の注記 |
| 第22節 Ｃ大阪 対 浦和 | 2017-07-22。原本には浦和のスルガ銀行チャンピオンシップ出場に伴う日程注記 |

第13節は05-27～07-05、第22節は07-22～08-13、第28節は09-30～10-01にまたがる。
原本順で節番号が戻る箇所は2箇所ある。原本の行順・実施日を維持し、節順を時系列順の代わりにしない。
対象306行のスコアには未確定・中止・PK表記がなく、すべて得点2列へ変換できた。
