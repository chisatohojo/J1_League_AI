## Main diagnosis

主要な損失寄与はDraw（NLL 35.7%、Brier 36.9%）。またnear-even、2022/2024、昇格クラブ関与試合でLog Lossが高い。strong favoriteはサンプルが17試合と少ないが、>=0.70では過信傾向が見える。

次に調べる価値がある情報領域は、実装せず候補としてのみ挙げる。

1. draw probability calibration
2. near-even fixtureの追加context
3. promoted-clubのseason transition情報

model、feature、threshold、parameterは変更していない。
